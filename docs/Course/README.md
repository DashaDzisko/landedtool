## Vibecoding course — JobTracker / Landed edition

This is the vibecoding course, tailored to a real repo. Instead of generic examples, every lesson uses **JobTracker** (called **"Landed"** in the code) — an AI, chat-first job application tracker. You get a chat agent on the left and a status Kanban of your applications on the right. The stack is **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Supabase**, and **OpenAI**. You will learn how to work with AI by building on the same app you are reading about.

## What's inside

- [01-setup/](01-setup/) — Set up AI to understand the project: what a `claude.md` is, what rules are, how to write good instructions, and how the project is structured.
- [02-first-project/](02-first-project/) — Get the app running on your machine and learn the "why before code" idea (Markdown and OOUX).
- [03-prompts/](03-prompts/) — How to talk to AI. Writing clear prompts, giving context, and asking for changes step by step.
- [04-tools/](04-tools/) — The tools around your code: the terminal, git, Storybook, tests, and how AI uses them.
- [05-design-to-code/](05-design-to-code/) — Turning a design into real components. Design tokens, atomic design, and matching Figma to the app.
- [06-debugging/](06-debugging/) — What to do when something breaks. Reading errors, asking AI for fixes, and checking the result.
- [07-resources/](07-resources/) — Bookmarks, UI kits, and other materials.
