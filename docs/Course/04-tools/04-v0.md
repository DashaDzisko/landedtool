
## What it is

v0 is a tool made by Vercel that generates UI components. You describe what you want, and it creates React components with Tailwind CSS. It is focused on design and UI, not full apps.

Think of it as a component generator. You ask for a navbar, a pricing card, or a dashboard layout, and v0 gives you the code.

## How it works

Go to v0.dev. Describe what you want. v0 shows you a preview and the code. You can copy the code and paste it into your project.

You can also ask v0 to change things. "Make the card wider." "Add an icon to the button." "Change the colors to dark mode."

## What it is good for

- Generating UI components fast. Buttons, cards, forms, tables, navigation.
- Getting design ideas. Ask for "a modern application card" and see what it creates.
- Building layouts. "Create a two-pane layout with a chat panel and a board area."
- Learning how components are built. Read the code v0 generates to understand the structure.

## What it is NOT good for

- Full apps. v0 makes components, not complete applications.
- Backend logic. It does not connect to APIs, databases, or authentication.
- Complex interactions. It handles static UI well but not complex state or data flow.

## How to use it in your project

1. Go to v0.dev and describe the component you need.
2. Review the preview. Make adjustments.
3. Copy the code.
4. Paste it into your project as a new component file.
5. Adjust the colors and fonts to match your design system.

Or ask your AI tool (Claude Code, Cursor) to integrate it:

"Here is a component from v0. Add it to /components/molecules/status-badge.tsx and update the colors to match our design system."

## Tips

- v0 uses shadcn/ui components by default. These are popular and well-made, but they might need adjustments to match your design. Our repo does not use shadcn/ui — it uses Radix UI primitives plus Tailwind v4, so v0 output may need adapting to our tokens in `app/globals.css` (things like `bg-canvas`, `text-ink`, and the salmon `text-primary`).
- Use v0 for inspiration when you are stuck on a layout. Even if you do not copy the code, seeing the structure helps.
- Always check that the component is responsive. v0 usually handles this, but double check on mobile.
- Do not use v0 for every component. Simple things (a heading, a paragraph) do not need a generator. Use v0 for complex UI pieces.
