
## What they are

Bolt and Lovable are browser-based tools that build web apps for you. You describe what you want, and they generate a full working app. No terminal. No code editor. Everything happens in your browser.

They are the fastest way to go from idea to working prototype.

## How they work

You go to the website (bolt.new or lovable.dev). You describe your app in plain text. The tool creates the code, shows you a live preview, and lets you make changes by chatting.

You can see the app running in real time. You click, type, and test it right in the browser.

## What they are good for

- Quick prototypes. "Build me a job tracker with a Kanban board and status columns."
- Testing an idea fast. You can have a working app in minutes.
- Building simple apps without touching a terminal or code editor.
- Showing a concept to someone. You get a shareable link.

## Bolt

Bolt is made by StackBlitz. It runs a full development environment in your browser.

What makes it special:
- It creates a real project you can download and continue working on.
- You can install packages, edit code, and see the preview side by side.
- It supports Next.js, React, and other frameworks.
- You can deploy directly from Bolt.

## Lovable

Lovable focuses on building apps through conversation. It feels like chatting with a developer.

What makes it special:
- Very conversational. You describe what you want and it builds it.
- It connects to Supabase for databases and authentication.
- It can deploy your app for you.
- Good for full apps, not just UI components.

## Limits

Both tools have limits you should know about:

- **Less control.** You cannot fine-tune things as precisely as in Cursor or Claude Code.
- **Complex apps get messy.** For simple apps they work great. For larger projects, the code can get hard to manage.
- **Paid plans.** The free tiers have limits on how many messages or projects you can create.
- **Moving out is tricky.** You can download the code, but it might need cleanup before you continue in a local editor.

## When to use them

Use Bolt or Lovable when:
- You want to test an idea quickly.
- You are building something simple.
- You do not want to set up a local project yet.
- You want to show a working prototype to someone.

Switch to Claude Code or Cursor when:
- Your project gets more complex.
- You need more control over the code.
- You want to connect APIs and databases with more precision.
- You want to work on the project long term.

## Tips

- Start with a clear description. The more specific you are, the better the result.
- Make small changes. Do not ask for five things at once.
- Download your code if you want to keep working on it later. Do not rely only on the browser version.
- Use them for prototyping. Use Cursor or Claude Code for building the real thing.
