
## UI-киты и библиотеки компонентов

Это хорошие места, где можно найти готовые, хорошо сделанные компоненты и вдохновение. Те, что помечены "used here", подходят под стек этого проекта: React + Tailwind + Radix.

### Работает прямо в этом стеке (React / Tailwind)

- [shadcn/ui](https://ui.shadcn.com/) — красиво сделанные компоненты, которые ты копируешь и вставляешь в своё приложение. Этот проект собран в таком же стиле.
- [Radix UI](https://www.radix-ui.com/) — открытые, доступные примитивы компонентов. **Используется в этом проекте.**
- [Tailwind Plus (UI Blocks)](https://tailwindcss.com/plus/ui-blocks) — индустриальный стандарт, сборник компонентов Tailwind.
- [Preline UI](https://preline.co/) — открытая библиотека компонентов на Tailwind CSS.
- [React Bits](https://reactbits.dev/get-started/index) — React-компоненты для креативных разработчиков.
- [Untitled UI](https://www.untitledui.com/) — один из крупнейших UI-китов и дизайн-систем (Figma + код на React).

### Для дизайна и вдохновения (референс)

- [Material Design 3](https://m3.material.io/components) — интерактивные строительные блоки от Google; эталонный стандарт.
- [Fluent UI](https://react.fluentui.dev/?path=/docs/concepts-introduction--docs) — библиотека React-компонентов от Microsoft; хороший референс по паттернам.
- [Elastic UI (EUI)](https://eui.elastic.co/) — зрелая дизайн-система на React, которую внутри используют в Elastic.
- [Shaders.com](https://shaders.com/) — библиотека WebGPU-шейдеров с редактором; полезно посмотреть, что вообще возможно.

### Иконки

- [Phosphor Icons](https://phosphoricons.com/) — набор иконок, **используемый в этом проекте**.
- [Lucide](https://lucide.dev/) — чистый, популярный открытый набор иконок.

## Как этим пользоваться

- Бери компоненты из группы "работает прямо" и адаптируй их цвета и отступы под наши дизайн-токены в `app/globals.css`.
- Используй группу "референс" для идей, даже если не копируешь код.
- Держи в голове доступность. Radix и эти киты помогают с поддержкой клавиатуры, фокусом и скринридерами.
