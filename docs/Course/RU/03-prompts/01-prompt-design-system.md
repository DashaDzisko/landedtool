

## Что делает этот промпт

Этот промпт просит ИИ собрать страницу-витрину дизайн-системы для Landed. Это одна страница, где ты видишь все свои строительные блоки в одном месте: цвета, стили текста, кнопки, поля ввода, бейджи статусов и карточки.

В Landed такая страница уже есть. Она живёт по адресу `/design` и рендерится файлом `components/design-system/showcase.tsx`. Она полезна, потому что ты можешь проверить, что всё выглядит согласованно, ещё до того, как начнёшь собирать настоящие экраны. Токены берутся из `app/globals.css`, поэтому страница всегда показывает реальные значения.

## Промпт

Скопируй это. Цвета, шрифты и размеры ниже — это реальные токены Landed, так что можешь использовать их как есть.

---

```
Собери страницу дизайн-системы по адресу /design.

Эта страница показывает все переиспользуемые части нашего приложения в одном месте. Она использует тёмную тему. У каждой секции есть крупный заголовок, короткое описание и живые примеры.

- Фон страницы: #0d0d0d (наш цвет холста). Текст: #ffffff.
- Шрифты: "Strichpunkt Sans" для всего, "JetBrains Mono" для кода и чисел.
- Центрируй контент, максимальная ширина 1100px. Разделяй секции большим количеством пространства.
```

## Как этим пользоваться

1. Убедись, что твои токены лежат в `app/globals.css`. Это Tailwind v4, поэтому файла `tailwind.config.ts` нет — цвета и размеры это CSS-переменные внутри блока `@theme inline`.
2. Вставь промпт в свой ИИ-инструмент.
3. Открой `http://localhost:3009/design` и проверь, что цвета, шрифты и бейджи совпадают.
4. Исправляй по одной вещи за раз. Например: «Бейдж interview должен быть более оранжевым. Используй text #f4a988.»

## Советы

- Поменяй токен в `globals.css` один раз — и каждая секция на этой странице обновится. В этом весь смысл.
- Оставь здесь все 7 бейджей статусов. Это сердце приложения, поэтому тебе важно видеть их вместе.
- Добавляй новые элементы на эту страницу по мере роста приложения: аватары, выпадающие списки, пузырь сообщения в чате.
- Эта страница также продублирована в Storybook (`npm run storybook`, порт 6006), если хочешь смотреть каждый элемент по отдельности.
