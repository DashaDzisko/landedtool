
## Что это такое

Framer Motion — это библиотека анимаций для React. С ней анимации строить проще, чем на чистом CSS. Ты оборачиваешь свои элементы в специальные компоненты и описываешь, как они должны анимироваться.

Если ты пользовался анимациями прототипирования в Figma, Framer Motion покажется знакомым. Ты задаёшь начальное состояние, конечное состояние, а библиотека сама делает движение между ними.

> Заметка: Framer Motion сейчас в этом репозитории не установлен. Landed поставляется без него. Это опциональное дополнение, которое ты бы установил, если фиче нужны анимации, с которыми CSS не справляется.

## Когда использовать

Используй Framer Motion, когда тебе нужны:
- Элементы, которые анимируются при появлении на экране
- Переходы между страницами (плавная смена страниц)
- Взаимодействия с перетаскиванием
- Пружинная физика и отскок
- Анимации, зависящие от позиции скролла
- Анимированные раскладки (элементы, которые двигаются при изменении списка)

Для простых эффектов при наведении и переходов CSS достаточно. Framer Motion — для следующего уровня.

## Как установить

```bash
npm install framer-motion
```

Или попроси AI: «Установи framer-motion.»

## Базовые примеры

### Появление при появлении элемента

```jsx
import { motion } from "framer-motion"

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5 }}
>
  This content fades in and moves up.
</motion.div>
```

`initial` — это начальное состояние. `animate` — конечное состояние. `transition` управляет скоростью.

### Анимация при прокрутке в зону видимости

```jsx
<motion.div
  initial={{ opacity: 0, y: 30 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true }}
  transition={{ duration: 0.6 }}
>
  This appears when you scroll to it.
</motion.div>
```

`whileInView` запускает анимацию, когда элемент становится видимым. `viewport={{ once: true }}` означает, что он анимируется только один раз, а не каждый раз, когда ты прокручиваешь мимо.

### Анимация при наведении

```jsx
<motion.button
  whileHover={{ scale: 1.05 }}
  whileTap={{ scale: 0.95 }}
  transition={{ type: "spring", stiffness: 300 }}
>
  Click me
</motion.button>
```

Кнопка увеличивается при наведении и уменьшается, когда ты кликаешь. Пружинная физика делает её как живую.

### Каскад дочерних элементов (stagger)

Когда у тебя есть список элементов и ты хочешь, чтобы они появлялись один за другим (например, карточки заявок внутри Канбан-колонки):

```jsx
<motion.div
  initial="hidden"
  animate="visible"
  variants={{
    hidden: {},
    visible: { transition: { staggerChildren: 0.1 } }
  }}
>
  {applications.map((app) => (
    <motion.div
      key={app.id}
      variants={{
        hidden: { opacity: 0, y: 20 },
        visible: { opacity: 1, y: 0 }
      }}
    >
      {app.role}
    </motion.div>
  ))}
</motion.div>
```

Каждый элемент появляется на 0.1 секунды позже предыдущего.

«Добавь анимацию появления для карточек заявок. Используй Framer Motion. Карточки должны плавно появляться и сдвигаться вверх при появлении. Сделай каскад с интервалом 0.1 секунды.»

«Добавь переход между видом доски и видом деталей. При переключении старый вид плавно исчезает, а новый плавно появляется. Используй Framer Motion AnimatePresence.»

«Сделай так, чтобы новое сообщение в чате анимированно появлялось. Оно должно выезжать вверх с 20px ниже с пружинной анимацией. Используй Framer Motion.»

## Советы

- Используй `once: true` для анимаций по скроллу. Без этого элементы будут заново анимироваться каждый раз, когда ты прокручиваешь мимо. Это раздражает.
- Пружинные анимации ощущаются естественнее, чем линейные. Используй `type: "spring"` для интерактивных элементов вроде кнопок и карточек.
- Не анимируй всё подряд. Выбери 2-3 элемента на экран. Слишком много анимаций отвлекают.
- Framer Motion увеличивает размер бандла. Если тебе нужны только простые эффекты при наведении, оставайся на CSS.
- Тестируй на мобильном. Некоторые анимации, которые плавны на десктопе, на телефонах могут быть медленными.
