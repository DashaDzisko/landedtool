
## Что это такое

WebGL позволяет показывать 3D-графику в браузере. Интерактивные 3D-объекты, эффекты частиц, анимированные фоны и погружающие визуальные впечатления. Если ты видел сайт с вращающимся 3D-продуктом, парящими частицами или интерактивным глобусом — это WebGL.

Сам по себе WebGL очень сложный. Но библиотеки вроде Three.js и React Three Fiber сильно упрощают дело.

> Заметка: Three.js и React Three Fiber сейчас в этом репозитории не установлены. Landed поставляется без них. Это опциональные дополнения, которые ты бы установил, если странице (например, промо-лендингу) действительно нужен 3D-эффект.

## Когда использовать

Используй WebGL, когда тебе нужны:
- 3D-объекты на сайте (просмотрщики продуктов, 3D-модели)
- Интерактивные эффекты частиц
- Анимированные 3D-фоны
- Визуализации данных в 3D
- Погружающие впечатления и креативные портфолио

Не используй WebGL для обычных экранов приложения. Он тяжёлый. Он замедляет страницы и жрёт много батареи. Используй его только тогда, когда 3D-эффект — это главная фича, а не украшение. Основному каркасу Landed (чат + Канбан) он не нужен.

## Библиотеки

### Three.js

Самая популярная WebGL-библиотека. Она берёт на себя сложную 3D-математику. Ты создаёшь сцены, добавляешь объекты, настраиваешь свет и двигаешь камеру.

```bash
npm install three
```

### React Three Fiber

React-обёртка для Three.js. Поскольку Landed использует React (Next.js 16), это лучший способ добавить 3D. Ты пишешь 3D-сцены с помощью React-компонентов.

```bash
npm install @react-three/fiber @react-three/drei
```

`@react-three/drei` — вспомогательная библиотека с готовыми компонентами вроде камер, света, текста и загрузчиков.

## Простой пример

Вращающийся 3D-куб:

```jsx
import { Canvas } from "@react-three/fiber"
import { OrbitControls } from "@react-three/drei"

function SpinningBox() {
  return (
    <mesh rotation={[0.5, 0.5, 0]}>
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial color="#f4a988" />
    </mesh>
  )
}

export default function Scene() {
  return (
    <Canvas style={{ height: "400px" }}>
      <ambientLight intensity={0.5} />
      <directionalLight position={[5, 5, 5]} />
      <SpinningBox />
      <OrbitControls />
    </Canvas>
  )
}
```

## Производительность

WebGL тяжёлый. Следуй этим правилам:

- **Держи проще.** Несколько объектов — нормально. Сотни детализированных объектов сделают страницу медленной.
- **Используй ленивую загрузку.** Не загружай 3D-контент, пока пользователь не прокрутит до него.
- **Добавь запасной вариант.** Некоторые старые телефоны и браузеры не поддерживают WebGL. Показывай вместо него статичное изображение.
- **Тестируй на мобильном.** 3D намного медленнее на телефонах. Снижай качество или прячь 3D на маленьких экранах.

Попроси AI: «Добавь проверку поддержки WebGL. Если браузер её не поддерживает, показывай статичное изображение вместо 3D-сцены.»

## Советы

- Начинай с React Three Fiber, а не с чистого Three.js. Он лучше ложится на React-проекты.
- Используй `@react-three/drei` для готовых хелперов. Камеры, контролы, текст, полосы загрузки. Это экономит кучу работы.
- Не добавляй WebGL на каждую страницу. Используй его на одной ключевой странице, например на promo hero.
- 3D сложно дебажить. Если что-то не показывается, проверь сначала позицию камеры и освещение. Часто объект на месте, но камера смотрит куда-то в другую сторону.
- AI хорошо пишет базовый код Three.js. Но для очень сложных сцен тебе, возможно, придётся освоить какие-то основы или свериться с документацией Three.js.
