
## Основная идея

У тебя есть дизайн в Figma. Ты хочешь получить его в коде. Есть несколько способов это сделать — от простого к продвинутому.

## Способ 1: скриншоты

Самый простой способ. Сделай скриншот своего дизайна и отдай его AI-инструменту.

«Собери этот компонент. Вот скриншот дизайна.»

Это работает, но AI угадывает некоторые значения. Он может немного ошибиться с точными отступами или размером шрифта.

**Когда использовать:** быстрые прототипы. Когда тебе не нужен пиксель-в-пиксель результат.

## Способ 2: скриншоты со спецификацией

Сделай скриншот и заодно выпиши ключевые значения.

«Собери компонент карточки заявки. Вот скриншот. У карточки padding 20px, радиус скругления 12px, шрифт Strichpunkt Sans 15px и цвет фона #1a1a1a.»

Так гораздо лучше. AI берёт структуру из скриншота, а точные значения — из твоей спецификации.

**Когда использовать:** когда хочешь результат ближе к дизайну, но не хочешь настраивать MCP.

## Способ 3: Figma MCP

Подключи Figma напрямую к своему AI-инструменту (смотри гайд по Figma MCP). AI сам читает файл дизайна. В Landed уже подключён Figma MCP и есть файл дизайна для приложения, так что здесь стоит тянуться именно к этому способу.

«Собери этот компонент из моего фрейма в Figma: [ссылка]»

Это даёт лучший результат, потому что AI читает точные значения из Figma.

**Когда использовать:** когда хочешь самый точный результат и у тебя настроен MCP.

## Экспорт ассетов из Figma

AI не может создать твои картинки, иконки или иллюстрации из файла дизайна. Их нужно экспортировать из Figma.

### Иконки

В Landed для большинства иконок уже используется `@phosphor-icons/react`, так что часто экспортировать вообще не нужно. Для кастомных значков, которых нет в этом наборе:

1. Выдели иконку в Figma.
2. Правая панель > Export > SVG.
3. Нажми Export.
4. Положи SVG-файл в папку проекта `/public` (приложение хранит там же SEO- и маркетинговые изображения).

Используй SVG для иконок. Они масштабируются до любого размера и остаются чёткими.

### Изображения

1. Выдели изображение в Figma.
2. Правая панель > Export > PNG at 2x.
3. Нажми Export.
4. Положи изображение в папку проекта `/public`.

Экспортируй в 2x, чтобы изображения хорошо выглядели на экранах с высоким разрешением.

### Советы по экспорту

- Называй файлы понятно. `promo-hero.png` лучше, чем `image-1.png`.
- Используй нижний регистр и дефисы. `application-card-icon.svg`, а не `ApplicationCardIcon.SVG`.
- Держи все ассеты в одной папке. Не разбрасывай их по проекту.

## Дизайн-токены

Дизайн-токены — это значения из твоей дизайн-системы: цвета, шрифты, отступы, радиусы скругления. Они — мост между твоим дизайном и кодом.

Токены из Figma можно получить несколькими способами:

### Переменные Figma

Если ты используешь переменные Figma, твои токены уже организованы. Figma MCP может читать их напрямую.

### Плагины

Плагины Figma вроде «Tokens Studio» могут экспортировать твои дизайн-токены в JSON. Ты можешь дать этот файл AI и попросить связать значения.

### Где живут токены в Landed

Этот проект использует Tailwind CSS v4, поэтому файла `tailwind.config.ts` нет. Токены живут как CSS-переменные в `app/globals.css`, внутри блока `@theme inline`. Это значит, что классы вроде `bg-canvas`, `text-ink` и `text-primary` напрямую ложатся на эти переменные. Когда переносишь компонент из Figma, попроси AI переиспользовать существующие токены (например, salmon-цвет primary `#f4a988` и тёмные поверхности) вместо того, чтобы вставлять сырые hex-значения.

## Советы

- Начинай со способа, который кажется лёгким. Скриншоты вполне сгодятся для твоего первого компонента.
- Способы можно смешивать. Используй скриншоты для раскладки и спецификацию для точных значений.
- Всегда проверяй результат в браузере. Figma и браузер рендерят вещи по-разному. Небольшие различия — это нормально. Dev-сервер работает на `http://localhost:3009`.
- Когда что-то не совпадает, скажи AI конкретную разницу. «Padding должен быть 20px, а не 16px.»
