
## Что это такое

GSAP расшифровывается как GreenSock Animation Platform. Это мощная библиотека анимаций, которую используют профессиональные студии и агентства. Если ты видел сайт с впечатляющими анимациями по скроллу, появлением текста или плавным параллаксом, скорее всего, там GSAP.

GSAP сложнее, чем Framer Motion, но умеет больше. Это индустриальный стандарт для продвинутых веб-анимаций.

> Заметка: GSAP сейчас в этом репозитории не установлен. Landed поставляется без него. Это опциональное дополнение, которое ты бы установил, если фиче (например, анимированной промо-лендинг-странице) нужны эффекты по скроллу или таймлайны.

## Когда использовать

Используй GSAP, когда тебе нужны:
- Анимации по скроллу с точным контролем
- Анимации-таймлайны (шаг 1, потом шаг 2, потом шаг 3 по очереди)
- Анимации текста (буквы появляются одна за другой)
- Эффекты параллакса при скролле
- Закрепление элементов при скролле (элемент остаётся на месте, пока контент прокручивается)
- Сложные анимации, с которыми не справляются CSS и Framer Motion

## Как установить

```bash
npm install gsap
```

У GSAP также есть плагин ScrollTrigger для анимаций на основе скролла, плюс React-хелпер:

```bash
npm install gsap @gsap/react
```

Или попроси AI: «Установи GSAP с плагином ScrollTrigger.»

## Ключевые понятия

### Твины (tweens)

Твин — это одна анимация. Ты говоришь GSAP, что анимировать, из какого состояния, в какое состояние и как долго.

```jsx
gsap.to(".box", { x: 200, duration: 1 })
```

Это сдвигает элемент с классом «box» на 200px вправо за 1 секунду.

- `gsap.to()` - анимировать из текущего состояния в новое
- `gsap.from()` - анимировать из состояния в текущее
- `gsap.fromTo()` - анимировать из одного состояния в другое

### Таймлайны

Таймлайн позволяет связывать анимации в цепочку. Одна происходит после другой.

```jsx
const tl = gsap.timeline()
tl.from(".heading", { opacity: 0, y: 30, duration: 0.5 })
  .from(".description", { opacity: 0, y: 20, duration: 0.4 })
  .from(".button", { opacity: 0, scale: 0.9, duration: 0.3 })
```

Сначала появляется заголовок, потом описание, потом кнопка.

### ScrollTrigger

ScrollTrigger связывает анимации с позицией скролла. Элементы анимируются, когда ты прокручиваешь до них.

```jsx
gsap.from(".feature-card", {
  scrollTrigger: {
    trigger: ".feature-card",
    start: "top 80%",
  },
  opacity: 0,
  y: 50,
  duration: 0.6,
  stagger: 0.2
})
```

Карточки фич плавно появляются и сдвигаются вверх, когда ты прокручиваешь до них. `stagger: 0.2` заставляет каждую карточку анимироваться на 0.2 секунды позже предыдущей.

### Закрепление (pinning)

Закрепи элемент так, чтобы он оставался на экране, пока пользователь прокручивает.

```jsx
gsap.to(".hero-image", {
  scrollTrigger: {
    trigger: ".hero-section",
    start: "top top",
    end: "bottom top",
    pin: true,
  }
})
```

Hero-изображение остаётся закреплённым, пока секция hero прокручивается мимо.

## Как использовать GSAP в React/Next.js

GSAP требует небольшой настройки в React. Ты используешь `useRef` и `useEffect` (или GSAP-хук `useGSAP`).

Попроси AI: «Настрой GSAP с ScrollTrigger в моём Next.js-проекте. Создай переиспользуемый хук, который я смогу применить на любом компоненте.»

AI сделает настройку за тебя. Тебе не нужно разбираться в деталях React.

## GSAP против Framer Motion

| | Framer Motion | GSAP |
|---|---|---|
| Лучше всего для | Анимаций React-компонентов | Анимаций по скроллу и таймлайнов |
| Сложность | Проще | Сложнее |
| Анимации по скроллу | Базовые | Очень мощные |
| Таймлайны | Ограниченные | Полный контроль |
| Анимации текста | Вручную | Встроенные плагины |
| Размер бандла | Меньше | Больше |

Обе можно использовать в одном проекте. Framer Motion — для анимаций компонентов (наведение, появление). GSAP — для эффектов по скроллу и сложных таймлайнов.

## Советы

- Начинай с простых анимаций по скроллу. Появление + сдвиг вверх при скролле уже достаточно, чтобы страница ожила.
- Убирай анимации, когда компоненты размонтируются. Попроси AI позаботиться об этом. «Убедись, что анимации GSAP очищаются, когда компонент размонтируется.»
- Используй документацию GSAP на gsap.com. Там отличные наглядные примеры.
- Не перебарщивай. Несколько удачно расставленных анимаций по скроллу лучше, чем когда при скролле движется каждый элемент.
