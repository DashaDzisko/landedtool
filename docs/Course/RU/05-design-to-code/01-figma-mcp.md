
## Что такое MCP

MCP — это Model Context Protocol. Это способ подключать внешние инструменты к твоему AI. Когда ты подключаешь Figma через MCP, твой AI-инструмент видит дизайны в Figma напрямую. Он читает слои, цвета, шрифты, отступы и структуру компонентов.

Без MCP тебе приходится делать скриншоты и описывать дизайн словами. С MCP AI сам читает файл дизайна.

## В этом проекте это уже подключено

Landed поставляется с уже подключённым Figma MCP, и для приложения есть файл дизайна в Figma. Это значит, что ты можешь читать настоящий дизайн прямо в код. Когда ты укажешь Claude на фрейм из файла Landed, он прочитает точные цвета, шрифты и отступы и напишет код, который совпадает с дизайном, — вместо того чтобы ты всё описывал заново.

## Почему это важно для дизайнеров

У тебя уже есть дизайны в Figma. С Figma MCP ты можешь сказать:

«Собери этот компонент по моему дизайну в Figma.»

AI видит точный дизайн. Он читает цвета, размеры, шрифты и раскладку. Он пишет код, который близко совпадает с твоим дизайном. Ты тратишь меньше времени на объяснения и правки.

## Как это настроить

У Figma есть два способа подключения: удалённый сервер (рекомендуется) и десктопный сервер. Удалённый сервер проще и у него самые свежие возможности.

### Вариант A: удалённый сервер (рекомендуется)

Он подключается к облаку Figma. Десктопное приложение Figma тебе не нужно.

В Claude Code:

1. Открой терминал и запусти Claude Code.
2. Введи `/mcp`, чтобы открыть настройки MCP.
3. Выбери `figma` из списка.
4. Выбери «Authenticate».
5. Откроется страница в браузере. Нажми «Allow Access», чтобы подключить свой аккаунт Figma.
6. Вернись в терминал. Ты должен увидеть «Authentication successful. Connected to figma.»
7. Введи `/mcp` ещё раз, чтобы проверить, что сервер Figma показан как подключённый.

Вот и всё. Теперь ты можешь вставлять ссылки на Figma, и Claude будет читать дизайн.

### Вариант B: десктопный сервер

Он работает через десктопное приложение Figma на твоём компьютере. Используй этот вариант, если так требует твоя компания.

1. Открой десктопное приложение Figma.
2. Открой файл дизайна.
3. Переключись в Dev Mode (переключатель на панели инструментов).
4. Ничего не выделяя на холсте, включи MCP-сервер в правой боковой панели.
5. В терминале выполни: `claude mcp add --transport http figma-desktop http://127.0.0.1:3845/mcp`
6. Перезапусти Claude Code.
7. Введи `/mcp`, чтобы проверить, что сервер Figma подключён.

### В Cursor

Cursor тоже поддерживает подключения через MCP. Ты добавляешь Figma MCP-сервер в настройках Cursor.

Смотри документацию Cursor для самых свежих инструкций, потому что это часто меняется.

## Как этим пользоваться

После подключения ты можешь дать AI ссылку на Figma, и он прочитает дизайн.

«Посмотри на этот фрейм в Figma и собери его как React-компонент: [вставь ссылку на Figma]»

AI читает фрейм и создаёт код, который совпадает с дизайном. Он берёт цвета, отступы, шрифты и раскладку из файла.

Можно также попросить его прочитать конкретные части:

«Какой размер шрифта у заголовка в этом фрейме Figma?»
«Какие цвета используются в этом компоненте?»

## Что AI может прочитать из Figma

- Имена и структуру слоёв
- Цвета (заливки, обводки)
- Семейство, размер, начертание, межстрочный интервал шрифта
- Отступы (padding) и промежутки
- Радиус скругления
- Варианты компонентов
- Настройки auto layout

## Что у AI выходит не очень

- Сложные градиенты и режимы наложения могут переноситься не идеально.
- Кастомные иллюстрации и иконки нужно экспортировать как изображения отдельно.
- Анимаций в файлах Figma нет. Их нужно описывать самому.

## Советы

- Называй слои в Figma понятно. Если слои называются «Frame 237» и «Rectangle 14», AI путается. Называй их «Chat Panel», «Kanban Column», «Application Card».
- Используй auto layout в Figma. Он ложится на flexbox в CSS. AI переводит его лучше.
- Используй переменные Figma для своих дизайн-токенов (цвета, отступы). AI может их прочитать и использовать в коде. В Landed токены уже заданы как CSS-переменные в `app/globals.css`, так что попроси AI переиспользовать их, а не выдумывать новые значения.
- Начинай с одного компонента за раз. Не проси AI собрать целую страницу из Figma за один заход.
