
## Что такое адаптивный дизайн

Адаптивный дизайн означает, что твоё приложение хорошо выглядит на всех размерах экрана. Десктоп, планшет и телефон. Раскладка меняется, чтобы поместиться на экране.

Ты уже знаешь это по Figma. Ты рисуешь разные версии для разных экранов. В коде ты делаешь то же самое с помощью брейкпоинтов.

## Брейкпоинты

Брейкпоинт — это ширина экрана, при которой меняется раскладка. В Tailwind CSS есть встроенные брейкпоинты:

- **sm** - 640px (большие телефоны)
- **md** - 768px (планшеты)
- **lg** - 1024px (небольшие ноутбуки)
- **xl** - 1280px (десктопы)
- **2xl** - 1536px (большие экраны)

В Tailwind ты сначала пишешь стили для мобильных, а потом добавляешь изменения для больших экранов:

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
```

Это означает:
- На мобильном: 1 колонка
- На планшетах (md): 2 колонки
- На десктопе (lg): 3 колонки

## Как рассказать AI про адаптивный дизайн

Будь конкретным насчёт того, что меняется на каждом размере.

**Плохо:** «Сделай адаптивным.»

**Хорошо:** «На мобильном ставь панель чата над Канбан-холстом. На десктопе располагай их рядом: чат слева, холст справа.»

**Хорошо:** «На мобильном Канбан-доска показывает по одной колонке статуса за раз с свайпом. На десктопе показывай все колонки в ряд.»

## Что такое плавная типографика

Плавная типографика означает, что размер твоего текста меняется плавно по мере того, как экран становится больше или меньше. Вместо скачка с 16px на мобильном до 32px на десктопе размер плавно перетекает между этими значениями.

Благодаря этому текст хорошо выглядит на каждом экране, а не только на тех брейкпоинтах, что ты задал.

## Как работает плавная типографика

Ты используешь CSS-функцию `clamp()`. Она принимает три значения:

```css
font-size: clamp(minimum, preferred, maximum);
```

Пример:
```css
font-size: clamp(1rem, 2.5vw, 2rem);
```

Это означает:
- Никогда не меньше 1rem (16px)
- Предпочтительный размер — 2.5vw (2.5% от ширины экрана)
- Никогда не больше 2rem (32px)

Текст плавно масштабируется между 16px и 32px в зависимости от размера экрана.

## Частые значения для плавной типографики

Вот значения, которые хорошо работают для большинства проектов:

```css
/* Body text */
font-size: clamp(1rem, 1vw + 0.75rem, 1.125rem);

/* H3 */
font-size: clamp(1.25rem, 1.5vw + 0.75rem, 1.5rem);

/* H2 */
font-size: clamp(1.5rem, 2vw + 1rem, 2rem);

/* H1 */
font-size: clamp(2rem, 3vw + 1rem, 3rem);

/* Display / Hero heading */
font-size: clamp(2.5rem, 5vw + 1rem, 4.5rem);
```

## Где живёт шкала шрифтов в Landed

Этот проект хранит свою шкалу шрифтов как CSS-переменные в `app/globals.css` (display 2.25rem, h1 1.625rem, h2 1.25rem, body 0.9375rem и так далее). Если хочешь, чтобы заголовок масштабировался плавно, отредактируй переменную в этом файле и оберни значение в `clamp()`. Так каждое место, где используется токен, обновится разом, и у тебя останется один источник правды.

## Как попросить AI добавить плавную типографику

«Добавь плавную типографику в проект. Используй CSS clamp() для переменных заголовков и body в app/globals.css. H1 должен быть между 26px и 40px. Body-текст между 15px и 17px.»

Или для конкретного элемента:

«Сделай заголовок promo hero плавным. Он должен масштабироваться между 40px и 72px с помощью clamp().»

## Советы

- Всегда проектируй сначала для мобильных. Начинай с самого маленького экрана и добавляй стили для больших.
- Тестируй на реальных размерах экрана. Используй инструменты разработчика в браузере (F12, потом клик на иконку телефона), чтобы проверить разные ширины.
- Плавная типографика убирает необходимость во множестве брейкпоинтов для типографики. Одно значение clamp() часто заменяет три-четыре медиазапроса.
- Не делай body-текст слишком мелким на мобильном. 16px — безопасный минимум для хорошей читаемости.
- Проверяй длину строк. На больших экранах строки текста не должны быть шире примерно 700px. Используй max-width на контейнерах с текстом.
