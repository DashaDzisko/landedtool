
## Почему начинать с CSS

CSS может справиться с большинством простых анимаций без каких-либо дополнительных библиотек. Эффекты при наведении, появления, плавные переходы, спиннеры загрузки. Никаких пакетов ставить не нужно. Никакого лишнего кода. Просто работает.

Используй сначала CSS-анимации. Тянись к библиотеке только тогда, когда CSS не может сделать то, что тебе нужно.

## Переходы (transitions)

Переход делает так, что изменение происходит плавно, а не мгновенно. Ты добавляешь его к элементу, и когда меняется свойство (например, цвет или размер), оно анимируется.

```css
.button {
  background-color: #f4a988;
  transition: background-color 0.2s ease;
}

.button:hover {
  background-color: #ef9d78;
}
```

Цвет кнопки плавно меняется за 0.2 секунды при наведении. Эти два значения — salmon-цвет primary проекта и его оттенок для hover.

### В Tailwind

В Tailwind v4 классы переходов встроены, а Landed выставляет свои токены как utility-классы (так что `bg-primary` ложится на salmon-переменную в `app/globals.css`):

```html
<button class="bg-primary hover:bg-primary-hover transition-colors duration-200">
  Click me
</button>
```

Частые классы переходов в Tailwind:
- `transition-all` - анимировать всё, что меняется
- `transition-colors` - анимировать изменения цвета
- `transition-opacity` - анимировать появление/исчезновение
- `transition-transform` - анимировать движение, масштаб, поворот
- `duration-200` - 200 миллисекунд
- `duration-300` - 300 миллисекунд
- `ease-in-out` - плавные начало и конец

## Появление при загрузке страницы

Сделай так, чтобы элементы появлялись плавно при загрузке страницы.

```css
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}

.fade-in {
  animation: fadeIn 0.5s ease forwards;
}
```

Элемент плавно появляется и слегка сдвигается вверх. Это тонкий эффект, который делает страницы более аккуратными. Он хорошо работает для приходящих сообщений в чате или для новой карточки заявки, появляющейся на холсте.

## Эффекты при наведении, которые дизайнеры используют чаще всего

### Масштаб при наведении

```html
<div class="hover:scale-105 transition-transform duration-200">
  Application card
</div>
```

Карточка слегка увеличивается при наведении. Хорошо для карточек и кликабельных элементов.

### Тень при наведении

```html
<div class="shadow-sm hover:shadow-lg transition-shadow duration-200">
  Application card
</div>
```

Тень становится больше при наведении. Делает элементы интерактивными на ощущение. На тёмном холсте (`#0d0d0d`) более светлая поверхность вроде `#242424` часто читается лучше, чем тяжёлая тень, так что попробуй заодно приподнимать фон.

### Выезжающее подчёркивание

Хорошо для навигационных ссылок. Подчёркивание выезжает слева при наведении, а не появляется мгновенно.

Попроси AI: «Добавь анимацию выезжающего слева подчёркивания при наведении для nav-ссылок. Подчёркивание должно выезжать слева с помощью псевдоэлемента, в salmon-цвете primary.»

## Спиннер загрузки

Простой спиннер для состояний загрузки:

```html
<div class="w-6 h-6 border-2 border-primary border-t-transparent rounded-full animate-spin"></div>
```

`animate-spin` в Tailwind вращает элемент бесконечно. Идеально для кнопок загрузки и лоадеров страниц. В панели чата также используется индикатор набора текста, пока агент отвечает, — это та же идея, сделанная через keyframes.

## Как попросить AI о CSS-анимациях

Будь конкретным насчёт того, что движется, как быстро и когда.

**Плохо:** «Добавь какие-нибудь анимации.»

**Хорошо:** «Добавь эффект при наведении для карточек заявок. При наведении карточка сдвигается вверх на 4px, а фон приподнимается до поверхности #242424. Используй переход 200ms.»

**Хорошо:** «Когда появляется новое сообщение в чате, пусть оно плавно появляется снизу. Это должно занимать 0.3 секунды.»

## Когда CSS недостаточно

CSS плохо справляется с такими вещами:
- Анимации по скроллу (элементы анимируются, пока ты прокручиваешь вниз)
- Сложные таймлайны (шаг 1, потом шаг 2, потом шаг 3)
- Анимации на физике (пружина, отскок с реалистичным движением)
- Анимация переходов между страницами

Для этого используй Framer Motion или GSAP. Смотри следующие гайды.

## Советы

- Держи анимации сдержанными. Небольшие движения (4-8px) и короткие длительности (200-300ms) выглядят профессионально. Большие движения отвлекают.
- Используй `ease-in-out` для большинства анимаций. Он начинается и заканчивается плавно.
- Не анимируй слишком много всего сразу. Одного-двух анимированных элементов на экран достаточно.
- Тестируй анимации на более медленных устройствах. То, что плавно на твоём ноутбуке, на телефоне может тормозить.
