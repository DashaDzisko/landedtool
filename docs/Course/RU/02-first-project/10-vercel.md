## Что такое Vercel

Vercel — это место, где твоё приложение живёт в интернете. Прямо сейчас JobTracker работает на твоём компьютере по адресу localhost:3009. Его видишь только ты. Vercel выкладывает его в сеть, чтобы любой человек по ссылке мог им пользоваться.

Этот процесс называется деплой.

## Почему Vercel

- Его делает та же команда, что делает Next.js. Они идеально работают вместе, а JobTracker работает на Next.js 16.
- У него есть бесплатный тариф, которого хватает для большинства проектов.
- Деплой автоматический. Ты пушишь код, а Vercel обновляет приложение.
- Он даёт тебе реальный URL, которым можно поделиться с людьми.

## Что нужно сначала

Твой код должен быть на GitHub. Vercel подключается к твоему GitHub-репозиторию и деплоит код оттуда. Смотри руководство по GitHub, если проекта ещё нет на GitHub.

## Как это настроить

### Шаг 1: Создай аккаунт Vercel

Зайди на vercel.com и зарегистрируйся. Регистрируйся через свой аккаунт GitHub. Так связь настроится проще.

### Шаг 2: Импортируй проект

Нажми «Add New» > «Project». Vercel покажет твои GitHub-репозитории. Найди JobTracker и нажми «Import».

### Шаг 3: Добавь переменные окружения

Перед деплоем добавь свои ключи. Зайди в «Environment Variables» и добавь каждый. Это те же ключи из твоего файла `.env.local`:

- `NEXT_PUBLIC_SUPABASE_URL` = URL твоего проекта Supabase
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` = твой ключ Supabase anon
- `OPENAI_API_KEY` = твой ключ OpenAI (только для сервера, питает чат-агента)
- `OPENAI_MODEL` = `gpt-4o-mini` (необязательно — оставь пустым, чтобы использовать значение по умолчанию)

Если пропустишь ключ OpenAI, приложение всё равно задеплоится, но чат-агент будет работать на mock-заглушке вместо настоящих ответов.

### Шаг 4: Деплой

Нажми «Deploy». Подожди минуту-две. Vercel собирает приложение и даёт тебе URL вроде `jobtracker.vercel.app`.

Вот и всё. Твоё приложение в сети.

## Аналитика уже подключена

В JobTracker уже включён `@vercel/analytics`. Как только приложение окажется на Vercel, ты получишь аналитику просмотров страниц без дополнительной настройки. Включи «Web Analytics» в панели Vercel — и данные начнут поступать.

## Автоматические обновления

Каждый раз, когда ты пушишь новый код на GitHub, Vercel деплоит его автоматически. Тебе не нужно ничего нажимать. Запушь код, подожди минуту — и твоё живое приложение обновлено.

## Свой домен

Бесплатный URL выглядит как `jobtracker.vercel.app`. Если хочешь свой домен, можешь купить его и подключить в настройках Vercel. Это необязательно. Бесплатный URL отлично подходит для тестов и показа проекта.

## Частые проблемы

**Сборка падает:** Vercel показывает лог ошибки. Скопируй ошибку и попроси ИИ помочь её исправить. Большинство ошибок сборки — это недостающие пакеты или неправильные импорты. Помогает сначала запустить `npm run build` на своём компьютере — если собирается локально, почти наверняка соберётся и на Vercel.

**Отсутствуют переменные окружения:** Если приложение работает на твоём компьютере, но не на Vercel, проверь, что ты добавил все четыре ключа в панели Vercel. Это самая частая проблема. Типичный симптом — приложение загружается, но не показывает данных (нет ключей Supabase) или чат-агент даёт только mock-ответы (нет ключа OpenAI).

**Изменения не появляются:** Убедись, что ты запушил код на GitHub. Vercel деплоит только код, который есть на GitHub, а не код на твоём компьютере.

## Советы

- Запускай `npm run build` локально перед деплоем. Если проходит на твоей машине, задеплоится.
- Проверяй панель Vercel после каждого деплоя. Она показывает, сработала сборка или упала.
- Если деплой ломает приложение, ты можешь откатиться к предыдущей версии в панели Vercel.
- Добавь ключи `NEXT_PUBLIC_` и `OPENAI_API_KEY` до первого деплоя, а не после.
