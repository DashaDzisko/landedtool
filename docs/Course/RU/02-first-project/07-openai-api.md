## Что это

OpenAI делает ИИ-модели, например GPT-4o. OpenAI API позволяет твоему приложению использовать эти модели. Приложение может генерировать текст, отвечать на вопросы или делать другие умные вещи.

Это не то же самое, что пользоваться ChatGPT в браузере. Когда ты используешь API, ИИ работает внутри твоего приложения. Твои пользователи общаются с ним через твой интерфейс, а не через сайт OpenAI.

В JobTracker OpenAI API питает **чат-агента** по имени «Landed» в левой панели. Пользователь спрашивает про поиск работы, а агент отвечает, используя его реальные отклики как контекст.

## Что агент делает в JobTracker

Агент — это не простой чат-бот. У него есть задача:

- Он читает профиль пользователя и его отклики и помогает разобраться в воронке.
- У него есть доступ **только на чтение** к откликам через **инструменты** (схемы инструментов лежат в `lib/ai/tools.ts`). Модель может вызвать инструмент вроде `list_applications`, чтобы получить свежие данные, а не гадать.
- Когда это уместно, модель вызывает инструмент `show_*`, чтобы интерфейс отрисовал под ответом красивый виджет (график статистики, карточку отклика, шортлист, смену статуса, черновик письма).
- Пока он не может менять статус или отправлять письма. Вместо этого он предлагает следующий шаг текстом.

Инструкции, которые задают всё это поведение — **системный промпт** — лежат в `lib/ai/prompts.ts`. Это тот файл, который нужно открыть, если ты хочешь изменить поведение агента.

## Как всё связано

Главное, что важно понять: модель вызывается **только с сервера**, никогда из браузера.

- API-ключ — это `OPENAI_API_KEY`. У него нет префикса `NEXT_PUBLIC_`, поэтому он остаётся на сервере.
- Единственное место, где он используется, — это API-маршрут `app/api/chats/[chatId]/route.ts`. Этот маршрут загружает контекст пользователя, стримит ответ модели обратно в браузер и сохраняет сообщение.
- По умолчанию используется модель **gpt-4o-mini**. Ты можешь заменить её через переменную окружения `OPENAI_MODEL`.
- Если ключ не задан, маршрут переключается на mock-агента (`lib/ai/mock-agent.ts`), чтобы приложение всё равно работало.

## Как это настроить

### Шаг 1: Создай аккаунт

Зайди на platform.openai.com и зарегистрируйся.

### Шаг 2: Пополни баланс

API не бесплатный. Ты платишь за то, что используешь. Пополни баланс для начала. $5–$10 достаточно, чтобы тестировать и собирать приложение.

### Шаг 3: Получи API-ключ

Зайди в раздел API Keys в своей панели. Нажми «Create new secret key». Скопируй ключ и сохрани в надёжном месте. Больше ты его не увидишь.

### Шаг 4: Добавь ключ в проект

В файл `.env.local` добавь:

```
OPENAI_API_KEY=sk-your-key-here

# Optional - defaults to gpt-4o-mini
# OPENAI_MODEL=gpt-4o-mini
```

**Важно:** этот ключ НЕ начинается с `NEXT_PUBLIC_`. Так он остаётся на стороне сервера, и пользователи его не видят.

Когда будешь деплоить на Vercel, этот ключ нужно будет добавить и туда. Смотри руководство по Vercel.

## Как работает оплата

Ты платишь за токены. Токены — это кусочки текста. Одно слово — это примерно один токен. Короткий абзац — около 50–100 токенов.

Агент отправляет профиль пользователя плюс сводку по его откликам с каждым сообщением, поэтому чат стоит чуть дороже, чем однострочный промпт. Но `gpt-4o-mini` дешёвая. Для тестов и сборки затраты обычно меньше пары долларов в месяц.

Ты можешь задать лимиты трат в панели OpenAI, чтобы не было сюрпризов.

## Важно: только на сервере

Твой API-ключ OpenAI должен оставаться секретным. Если кто-то найдёт твой ключ, он сможет тратить твой баланс.

JobTracker уже делает всё правильно: ключ читается только внутри серверного маршрута. Никогда не переноси вызов OpenAI в компонент, который работает в браузере. ИИ знает это правило, если ты ему скажешь:

«Вызывай OpenAI из серверного API-маршрута. Не раскрывай API-ключ на клиенте.»

## Советы

- Пока собираешь приложение, оставляй модель `gpt-4o-mini`. Она дешёвая и достаточно быстрая для агента.
- Задай лимит трат в панели OpenAI.
- Меняй поведение агента, редактируя системный промпт в `lib/ai/prompts.ts`, а не разбрасывая инструкции по разным местам.
- Добавляй или меняй то, что умеет агент, редактируя схемы инструментов в `lib/ai/tools.ts`.
- Нет ключа? Приложение всё равно работает на mock-агенте. Добавь ключ, когда захочешь настоящие ответы.
