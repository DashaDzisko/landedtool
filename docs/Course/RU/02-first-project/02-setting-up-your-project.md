

## Настройка этого проекта

Этот урок запускает Landed на твоём собственном компьютере. Ты не создаёшь новое приложение с нуля — оно уже существует. Ты скопируешь его, установишь его инструменты, добавишь свои ключи и запустишь.

Полный список команд (Storybook, тесты, линт) смотри в [11-running-the-project.md](./11-running-the-project.md). Эта страница — короткий путь к запущенному приложению.

## Что нужно сначала

Установи это, прежде чем начать:

1. **Node.js** — на нём работает приложение. Скачай его с nodejs.org и выбери версию **LTS** (ту, что отмечена как "Recommended").
2. **git** — он копирует проект на твою машину. На Mac обычно уже стоит. Набери `git --version`, чтобы проверить.
3. **Редактор кода** — используй Cursor или VS Code. В Cursor встроен ИИ. VS Code бесплатный и работает с Claude Code.
4. **Claude Code** — ИИ-агент, которым ты будешь строить. Ты также можешь позволить ему выполнить шаги настройки ниже за тебя.

## Два способа настроить

Ты можешь выполнить шаги сам в терминале. Или попросить своего ИИ-агента сделать это. Оба способа работают. Если ты новичок, посмотри, как агент делает это один раз, — тогда ты поймёшь, что произошло.

## Шаг 1: Получи проект

Клонируй репозиторий и зайди в папку:

```bash
git clone <the-repo-url> JobTracker
cd JobTracker
```

Затем открой его в редакторе:

```bash
cursor .
```

Или в VS Code:

```bash
code .
```

## Шаг 2: Установи инструменты

Проект перечисляет все свои инструменты в `package.json`. Установи их одной командой:

```bash
npm install
```

Она читает `package.json`, скачивает Next.js, React, Supabase, OpenAI и всё остальное и кладёт это в папку `node_modules`. Это может занять минуту. Делаешь это один раз (и ещё раз, когда инструменты меняются).

## Шаг 3: Добавь свои ключи

Приложению нужны ключи для Supabase и OpenAI. Есть файл-пример, который показывает, какие ключи нужны. Скопируй его:

```bash
cp .env.example .env.local
```

Теперь открой `.env.local` и впиши свои настоящие значения:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://<your-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon-key>
OPENAI_API_KEY=<your-openai-api-key>
# OPENAI_MODEL=gpt-4o-mini   # optional, this is the default
```

- Два значения `NEXT_PUBLIC_SUPABASE_*` берутся из настроек твоего проекта в Supabase.
- `OPENAI_API_KEY` берётся из твоего аккаунта OpenAI. У него **нет** префикса `NEXT_PUBLIC_` — специально, чтобы он оставался на сервере и никогда не попадал в браузер.
- `.env.local` в gitignore, так что твои ключи никогда не попадут в GitHub. Никогда не вставляй ключи в другие файлы.

## Шаг 4: Настрой базу данных

Таблицы базы данных (applications, chats, profiles и их правила) живут как файлы миграций в `supabase/migrations/`. Тебе нужно один раз применить их к своему проекту в Supabase.

Два способа:

- **SQL-редактор:** открой свой проект в Supabase, зайди в SQL-редактор и запусти файлы миграций по порядку (`0001_init.sql`, `0002_rls.sql`, `0003_storage.sql`).
- **CLI:** если у тебя установлен Supabase CLI, выполни:

```bash
supabase db push
```

Это создаёт таблицы и включает правила безопасности, которые держат данные каждого пользователя приватными.

## Шаг 5: Запусти приложение

Запусти дев-сервер:

```bash
npm run dev -- -p 3009
```

Затем открой в браузере **http://localhost:3009**. Ты должен увидеть Landed. Каждый раз, когда ты меняешь файл, страница обновляется сама.

## Или попроси своего ИИ-агента

Если ты используешь Claude Code, большую часть этого можно поручить агенту. Скажи что-то вроде:

«Установи зависимости, скопируй `.env.example` в `.env.local`, затем запусти дев-сервер на порту 3009.»

Агент выполняет команды и спрашивает разрешения по ходу дела. Свои секретные ключи в `.env.local` тебе всё равно нужно вставить самому — агент не должен заниматься ими за тебя.

## Что только что произошло

Теперь у тебя есть полное приложение, запущенное на твоей машине, подключённое к твоей собственной базе данных и ИИ-ключу. Ничто из того, что ты здесь делаешь, не затрагивает данные других людей. Отсюда можно начинать строить.

## Советы

- Если страница не загружается, посмотри в терминал на красную ошибку. Скопируй её и спроси у своего ИИ-агента, что она значит.
- Если чат-агент не отвечает, скорее всего, твой `OPENAI_API_KEY` пропущен или неверен в `.env.local`.
- Если ты видишь ошибки входа или пустых данных, скорее всего, миграции из Шага 4 не были применены.
- Порт для этого проекта — **3009**, а не привычный 3000. Если 3009 занят, терминал сообщит об этом.
