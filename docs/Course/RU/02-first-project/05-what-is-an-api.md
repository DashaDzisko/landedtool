

## Простое объяснение

API расшифровывается как Application Programming Interface. Звучит сложно. Это не так.

API — это способ для двух приложений общаться друг с другом.

Твоему приложению нужно что-то, чего у него нет. Список заявок. Залогиненный пользователь. Ответ ИИ. Поэтому оно спрашивает другой сервис, и сервис присылает это обратно. Этот разговор происходит через API.

## Пример из реальной жизни

Представь ресторан. Ты сидишь за столиком. Ты хочешь еду. Но ты не можешь сам зайти на кухню.

Официант несёт твой заказ на кухню. Кухня готовит еду. Официант приносит её обратно.

Официант — это API. Ты — приложение. Кухня — это сервис.

## Какие API использует Landed

Landed общается с двумя внешними сервисами и со своими внутренними маршрутами.

- **Supabase** — база данных и вход. Когда ты сохраняешь заявку на работу или входишь по magic link, приложение общается с Supabase.
- **OpenAI** — мозг чат-агента. Когда ты пишешь агенту, твой текст и данные твоих заявок отправляются в OpenAI, и он отвечает.
- **Собственные API-маршруты Landed** — небольшие эндпоинты внутри приложения, в `app/api/chats`. Панель чата в браузере сначала отправляет твоё сообщение сюда, и серверный маршрут затем безопасно общается с OpenAI.

Последняя часть важна. Браузер никогда не общается с OpenAI напрямую. Он общается с собственным маршрутом Landed, а маршрут общается с OpenAI. Так ключ OpenAI остаётся на сервере.

## Как проходит сообщение чата

Вот разговор с OpenAI по порядку:

1. Ты набираешь «Which application should I prioritize?» в чате.
2. Браузер отправляет это в маршрут Landed: `app/api/chats/[chatId]/route.ts`.
3. Этот маршрут добавляет твои заявки как контекст и вызывает API OpenAI.
4. OpenAI генерирует ответ и стримит его обратно в маршрут.
5. Маршрут стримит его в браузер, и появляется ответ агента.

Всё это происходит за пару секунд.

## API-ключи

Большинству API нужен ключ. API-ключ — как пароль. Он говорит сервису, кто ты и что тебе можно войти.

Ты получаешь свои ключи, когда регистрируешься в каждом сервисе, и кладёшь их в специальный файл под названием `.env.local`. Landed поставляется с файлом-примером, `.env.example`, который показывает, какие именно ключи нужны:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://<your-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon-key>
OPENAI_API_KEY=<your-openai-api-key>
# OPENAI_MODEL=gpt-4o-mini   # optional
```

Скопируй `.env.example` в `.env.local` и впиши свои настоящие значения. `.env.local` в gitignore, так что он остаётся на твоём компьютере и никогда не попадает в GitHub.

## Только для сервера или безопасно для браузера

Присмотрись к именам выше. Это самое важное правило на этой странице.

- **`NEXT_PUBLIC_SUPABASE_URL`** и **`NEXT_PUBLIC_SUPABASE_ANON_KEY`** начинаются с `NEXT_PUBLIC_`. Этот префикс означает «безопасно отправлять в браузер». Эти два предназначены быть публичными — Supabase защищает твои данные правилами безопасности, а не тем, что прячет этот ключ.
- **`OPENAI_API_KEY`** **не** имеет префикса `NEXT_PUBLIC_`. Это специально. Он остаётся на сервере, используется только внутри API-маршрута. Он никогда не отправляется в браузер, потому что любой, кто его получит, мог бы тратить твои деньги в OpenAI.

Так что правило простое: если ключ должен попадать в браузер, он получает `NEXT_PUBLIC_`. Если он должен оставаться секретным — не получает. Никогда не добавляй `NEXT_PUBLIC_` к `OPENAI_API_KEY`.

## Тебе не нужны глубокие детали

Тебе не нужно знать, как работают HTTP-запросы, или что такое заголовки и коды статусов. ИИ берёт эту часть на себя.

Тебе нужно знать три вещи:

1. API позволяют твоему приложению получать данные и ответы от других сервисов.
2. Тебе нужен ключ, чтобы использовать большинство API, и он идёт в `.env.local`.
3. Некоторые ключи безопасны для браузера (`NEXT_PUBLIC_*`), а некоторые должны оставаться только на сервере (`OPENAI_API_KEY`). Держи секретные секретными.

## Советы

- Если чат-агент не отвечает, скорее всего, твой `OPENAI_API_KEY` пропущен или неверен в `.env.local`.
- Никогда не вставляй ключ в обычный файл кода или в сообщение чата. Только в `.env.local`.
- Если ты когда-нибудь увидишь `OPENAI_API_KEY` с префиксом `NEXT_PUBLIC_`, это баг — убери префикс.
