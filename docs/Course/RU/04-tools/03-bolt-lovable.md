
## Что это

Bolt и Lovable — это инструменты в браузере, которые собирают веб-приложения за тебя. Ты описываешь, что хочешь, а они генерируют полноценное рабочее приложение. Ни терминала. Ни редактора кода. Всё происходит в браузере.

Это самый быстрый способ пройти путь от идеи до рабочего прототипа.

## Как они работают

Ты заходишь на сайт (bolt.new или lovable.dev). Описываешь своё приложение простым текстом. Инструмент создаёт код, показывает живой предпросмотр и даёт вносить изменения через чат.

Ты видишь приложение в реальном времени. Ты кликаешь, печатаешь и тестируешь прямо в браузере.

## Для чего они хороши

- Быстрые прототипы. «Собери мне трекер откликов с Канбан-доской и колонками статусов».
- Быстро проверить идею. Рабочее приложение может быть готово за минуты.
- Собирать простые приложения, не трогая терминал и редактор кода.
- Показать концепт кому-то. Ты получаешь ссылку, которой можно поделиться.

## Bolt

Bolt сделала StackBlitz. Он запускает полноценную среду разработки прямо в браузере.

Чем он особенный:
- Он создаёт настоящий проект, который можно скачать и продолжить над ним работать.
- Ты можешь ставить пакеты, править код и видеть предпросмотр рядом.
- Он поддерживает Next.js, React и другие фреймворки.
- Ты можешь деплоить прямо из Bolt.

## Lovable

Lovable делает упор на сборку приложений через разговор. Ощущается как переписка с разработчиком.

Чем он особенный:
- Очень разговорный. Ты описываешь, что хочешь, а он это собирает.
- Он подключается к Supabase для баз данных и аутентификации.
- Он может задеплоить приложение за тебя.
- Хорош для полноценных приложений, а не только для UI-компонентов.

## Ограничения

У обоих инструментов есть ограничения, о которых стоит знать:

- **Меньше контроля.** Ты не можешь настроить всё так же точно, как в Cursor или Claude Code.
- **Сложные приложения превращаются в кашу.** Для простых приложений они работают отлично. Для крупных проектов кодом становится тяжело управлять.
- **Платные планы.** У бесплатных тарифов есть лимиты на количество сообщений или проектов.
- **Переехать непросто.** Код можно скачать, но перед тем как продолжить в локальном редакторе, его, возможно, придётся почистить.

## Когда их использовать

Используй Bolt или Lovable, когда:
- Хочешь быстро проверить идею.
- Собираешь что-то простое.
- Пока не хочешь настраивать локальный проект.
- Хочешь показать кому-то рабочий прототип.

Переходи на Claude Code или Cursor, когда:
- Проект становится сложнее.
- Тебе нужен больший контроль над кодом.
- Ты хочешь точнее подключать API и базы данных.
- Ты хочешь работать над проектом вдолгую.

## Советы

- Начинай с чёткого описания. Чем конкретнее, тем лучше результат.
- Делай маленькие изменения. Не проси пять вещей сразу.
- Скачай свой код, если хочешь продолжить работу позже. Не полагайся только на браузерную версию.
- Используй их для прототипирования. А для настоящей сборки — Cursor или Claude Code.
