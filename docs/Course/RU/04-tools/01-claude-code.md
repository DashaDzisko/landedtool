
## Что это

Claude Code — это AI, который работает в твоём терминале. Ты даёшь ему инструкции, а он пишет код, создаёт файлы, запускает команды и правит твой проект. Он работает прямо с файлами на твоём компьютере.

Его сделала Anthropic — та же компания, что делает Claude.

## Два способа использовать

### Приложение Claude (самый простой старт)

Ты можешь пользоваться Claude Code прямо из приложения Claude на claude.ai/code или из десктопного приложения. Терминал не нужен.

Чем это удобно:
- Он делает скриншоты твоего приложения и видит, как оно выглядит.
- Ты можешь показать ему скриншот и сказать: «сделай так же».
- У него есть визуальный интерфейс. Ты пишешь, видишь изменения и смотришь результат.
- Он подключается к проекту так же, как версия для терминала.

Если ты дизайнер, начни отсюда. Возможность показать Claude то, что у тебя на экране, сильно упрощает общение.

### Версия для терминала

Ещё можно пользоваться Claude Code в терминале. Ты открываешь папку проекта и запускаешь его из командной строки. Так у тебя больше контроля, и опытным пользователям это быстрее.

## Как это работает

Ты общаешься с Claude Code как с разработчиком. Он читает твои файлы, понимает проект и вносит изменения.

Каждое изменение ты одобряешь или отклоняешь до того, как оно применится. Контроль остаётся у тебя.

## Для чего он хорош

- Собирать функции с нуля. «Добавь на Канбан-доску новую колонку для статуса „offer“».
- Чинить баги. «У меня вылезает ошибка, когда я открываю панель чата. Почини». Потом вставь текст ошибки.
- Рефакторить код. «Перенеси все запросы к Supabase в отдельный файл /lib/db».
- Настраивать проекты. «Создай новый проект на Next.js с TypeScript и Tailwind».
- Запускать команды. Он может ставить пакеты, запускать тесты и стартовать твоё приложение.

## Чем он отличается

- Он работает с твоими настоящими файлами. Он читает код, понимает структуру и вносит правки прямо в файлы.
- Он использует твой терминал. Он может запускать npm install, команды git и другие инструменты.
- Он читает документацию и правила проекта. В этом репозитории Claude Code читает документацию в `docs/` и конфиг в `.claude/`. Например, `.claude/launch.json` говорит ему запускать dev-сервер на порту 3009. Файл `CLAUDE.md` в корне репозитория — это место для правил проекта, и Claude Code следует ему в начале каждой сессии.
- Он спрашивает разрешение. Прежде чем создать или изменить файл, он показывает, что хочет сделать, и ты это одобряешь.

## Как начать

Установи его из терминала:

```bash
npm install -g @anthropic-ai/claude-code
```

Перейди в папку проекта и запусти его:

```bash
cd JobTracker
claude
```

Теперь пиши свои инструкции. Например:

«Прочитай проект и расскажи, что делает это приложение».

## Советы

- Начинай каждую сессию с понятной задачи. «Добавь бейдж статуса на карточку отклика».
- Если Claude Code сделал что-то не так, скажи ему об этом. «Это не то, что я хотела. Бейдж должен использовать цвет salmon из globals.css».
- Используй файл `CLAUDE.md`. Claude Code читает его в начале и следует твоим правилам. Ещё он читает документацию в `docs/`, так что держи её в актуальном состоянии.
- Большие функции разбивай на маленькие шаги. Один шаг — одно сообщение.

## Когда его использовать

Используй Claude Code, когда хочешь полный контроль над проектом и тебе комфортно в терминале. Это самый мощный вариант, потому что у него прямой доступ ко всем твоим файлам и инструментам.

Если терминал пугает, начни с Cursor. На Claude Code можно перейти позже.
