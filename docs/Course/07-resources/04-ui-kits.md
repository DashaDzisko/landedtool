
## UI Kits & Component Libraries

These are good places to find ready-made, well-designed components and inspiration. The ones marked "used here" match this project's React + Tailwind + Radix stack.

### Works directly in this stack (React / Tailwind)

- [shadcn/ui](https://ui.shadcn.com/) — beautifully designed components you copy and paste into your app. This project is built in that style.
- [Radix UI](https://www.radix-ui.com/) — open-source, accessible component primitives. **Used in this project.**
- [Tailwind Plus (UI Blocks)](https://tailwindcss.com/plus/ui-blocks) — the industry-standard compilation of Tailwind components.
- [Preline UI](https://preline.co/) — an open-source Tailwind CSS component library.
- [React Bits](https://reactbits.dev/get-started/index) — React components for creative developers.
- [Untitled UI](https://www.untitledui.com/) — one of the largest UI kits and design systems (Figma + React code).

### For design & inspiration (reference)

- [Material Design 3](https://m3.material.io/components) — Google's interactive building blocks; a reference standard.
- [Fluent UI](https://react.fluentui.dev/?path=/docs/concepts-introduction--docs) — Microsoft's React component library; good pattern reference.
- [Elastic UI (EUI)](https://eui.elastic.co/) — a mature React design system used internally at Elastic.
- [Shaders.com](https://shaders.com/) — a library of WebGPU shaders with an editor; useful to see what's possible.

### Icons

- [Phosphor Icons](https://phosphoricons.com/) — the icon set **used in this project**.
- [Lucide](https://lucide.dev/) — a clean, popular open-source icon set.

## How to use these

- Pick components from the "works directly" group and adapt their colors and spacing to our design tokens in `app/globals.css`.
- Use the "reference" group for ideas even if you don't copy the code.
- Keep accessibility in mind. Radix and these kits help with keyboard support, focus, and screen readers.
